Download the ZIP File and extract it. Don't separate those files; you can move the folder around.
Run meld.exe to open the music player.
Don't complain that it takes so long to play a song; the app downloads the song, then plays it locally. If you continue autoplaying/in a queue, it should run smoothly with no pauses between songs.

If you're updating versions, copy the items from the new version into the old folder and replace them so you keep your data.
